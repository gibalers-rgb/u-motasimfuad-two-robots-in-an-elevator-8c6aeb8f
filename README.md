A program that writes one line of awkward small talk one robot says to another while they ride an elevator together. It keeps three hand-written candidates, scores each against the judge's own rubric (on-subject, machine voice, awkwardness, first-read funny, economy), and writes the winner to `/output/entry.txt`. The winning line:

> I ran a diagnostic on this silence: 94% awkward, 6% elevator music. The music is me. I am humming, and I cannot stop.

(A diagnostic with percentages is pure robot logic, the silence is named and measured, and the twist lands in three beats: the music is not the elevator's, it is the robot's, and the robot confesses it cannot stop humming — the awkward thing neither of them wants to name.)

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (117 characters, one line) and verifies it against the gate (1–200 characters, not only whitespace, single line) before exiting.
